# Cápsula del Tiempo

Juego incremental en el navegador. Construyes una civilización y, cuando haces prestigio, pasan mil años y empiezas una nueva **encima de las ruinas** de la anterior. Lo que construiste antes se convierte en el yacimiento que excavas ahora.

**[Jugar aquí](https://persantyf.github.io/capsula-del-tiempo/)**

## Cómo se juega

1. **Construir**: edificios que producen comida, piedra y cultura.
2. **Avanzar**: gasta recursos para pasar de era.
3. **Excavar**: envía arqueólogos a las capas de abajo y saca artefactos con bonus permanentes.
4. **Terminar**: elige cómo acaba tu civilización (volcán, inundación, abandono...) y deja pasar 1000 años. Se crea una capa nueva.

Cada partida deja una capa visible y permanente: el prestigio no borra tu historia, la entierra.

## Tecnología

HTML, CSS y JavaScript sin dependencias ni build. Para jugar en local basta con abrir `index.html` en el navegador.
